MegaApp outreach console

One console for a team's cold email: campaigns, leads, replies and mailboxes, from the web or Claude.

my role Designed and built it: all 92 commits, in one week.

The problem

DevPlusOps runs its cold email in Instantly. The team needed one place to run campaigns, find new leads without overspending on paid email tools, check its sending domains and plan content, and wanted Claude to be able to do the same.

How it works

  1. Campaigns, leads, the reply inbox and sending mailboxes in one web app, with Instantly as the source of truth.
  2. Find leads: search for people, then a waterfall of three paid tools finds verified work emails, showing the most it can cost before anything is spent.
  3. Domain health grades every sending domain on SPF, DKIM, DMARC, blocklists and Google Postmaster data.
  4. Ask answers plain-English questions from live data, read-only, under a daily budget.
  5. Content reads a brand's website and the news and writes a 14-day post calendar with branded cards and short videos.
  6. Claude can do all of this through an MCP server, with a personal key for each person.

What changed

  • 753automated tests
  • 92commits in 7 days
  • 3paid email tools in one waterfall
  • $0.02for a 14-day, 8-post calendar

What I built

  • The whole app in Python with FastAPI and SQLite: one set of actions behind the web screens, a REST API and the MCP server.
  • Spending guards: costs shown before paid calls, paid calls never retried, daily caps on the AI features and a log of every credit spent.
  • Google sign-in through Cloudflare Access, with the app checking the signed token itself.
  • 753 automated tests that never call the real Instantly.
